# Выживи в теле Наруто

Ветвящаяся браузерная игра по фанфику S&N (панк-AU, Лондон и Нью-Йорк, 1970-е). 18+.

Играть: https://helen0-byte.github.io/sn-game/

## Что где лежит

| Папка | Что там |
|---|---|
| `index.html` | меню частей и движок |
| `prolog/` | готовый пролог «Шестнадцать» (часть 1), пока отдельной страницей |
| `js/core/` | движок: сцена, модели, эффекты, звук, счётчики, сохранения |
| `js/parts/` | тексты частей: `index.js` (список и замки), `p0_pohorony.js`, `demo.js` (витрина эффектов) |
| `models/` | **только сжатые** .glb и `manifest.json`, который говорит, что чьё |
| `tools/compress.mjs` | сжатие моделей |
| `docs/` | передача проекта, схема игры, как писать часть, как готовить модели |
| `vendor/three/` | three.js r128 и загрузчики, лежат здесь, чтобы не зависеть от CDN |

## Как проверить у себя

Нужен любой локальный сервер (из файла `index.html` модели не загрузятся):

```
npx http-server -p 8080 -c-1 .
```

Потом открыть http://localhost:8080. Добавь `?all` к адресу, чтобы открыть все готовые части без замков.
