# Meshy originals — additional batch

Nine byte-identical GLB originals, retaining source filenames. Paths in manifest.json are relative to this directory; it records source-matched SHA256, sizes, skins, and animation names. Identity is not visually verified. Old/young Kurama mapping remains unconfirmed. The Naruto-labelled original is archival only, not a replacement for models/characters/naruto.glb; no runtime integration or existing asset replacement is intended.

The earlier six originals are in PR #4. Eleven files in the supplied folder were skipped as byte-identical to those six (including five duplicate filenames without the `(1)` suffix). This additional batch should not duplicate them.

Structural inspection is not full Khronos validation or animation playback. The Hinata-labelled GLB has a skin and animation clips, but skirt/scarf behaviour during Walking remains untested.

Repository policy warning: .gitignore comments say uncompressed originals should not be stored in the repo and ignore models/_src/. This publication requires a policy decision; do not merge automatically. No LFS or external storage has been added.
