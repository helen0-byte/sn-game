# Meshy character originals

Six unchanged GLB source assets, retaining original filenames. See manifest.json for sizes, SHA256 hashes, skins, animation names and texture information. Character identities are unconfirmed; filenames are not visual verification.

These files are source assets only and are not integrated into the game. Structural inspection is not full Khronos validation or animation playback testing. Future web-ready derivatives should be created separately without overwriting these originals.

Paths in manifest.json are relative to this directory. The existing game manifest (models/manifest.json) and models/characters/ are unchanged; mapping of these files to characters (including old vs. young Kurama) is still unconfirmed.
