# Модели: как готовить, где хранить, как подключить

## Где что хранится

- **Оригиналы** (несжатые .glb, файлы ИИ-инструмента, скачанные со Sketchfab): у тебя на диске или в Google Drive. В репозиторий не кладём: GitHub не берёт файлы больше 100 МБ, а весь репозиторий лучше держать до 1 ГБ.
- **Сжатые .glb**: в `models/` этого репозитория. Персонажи в `models/characters/`, локации в `models/locations/`.
- Если сжатые модели вместе перерастут ~500 МБ, переносим их в Cloudflare R2 (10 ГБ бесплатно) и в `manifest.json` пишем полный адрес вместо имени файла.

## Что нужно от модели персонажа

- `.glb`, один файл на персонажа, текстуры внутри.
- T- или A-поза.
- Риг, если инструмент умеет. Если нет, прогоняем через Mixamo (кости `mixamorig…` движок узнаёт сам).
- 30–50 тыс. полигонов.
- Лицо отдельным материалом (например `Face`), тогда выражения лица делаются заменой текстуры: `faces/naruto_smile.webp` и т. д.
- Анимации из Mixamo можно положить в тот же .glb. Клип, названный как поза (`sit`, `walk`, `ground`…), играет вместо позы-заглушки.

## Как сжать

Один раз поставить инструменты (нужен Node.js):

```
npm install
```

Потом для каждой модели:

```
node tools/compress.mjs оригинал.glb models/characters/naruto.glb
```

Для сканов местности (фотограмметрия, как кладбище) обычное упрощение почти ничего не даёт, нужен грубый режим:

```
node tools/compress.mjs оригинал.glb models/locations/имя.glb --ratio 0.2 --sloppy
```

`--ratio` это доля треугольников, которая останется, `--tex` это максимальный размер текстуры (по умолчанию 2048).

Пример: кладбище 130 МБ, 2,7 млн треугольников → 3,7 МБ, 530 тыс. треугольников (`--ratio 0.2 --sloppy`).

Если сжимать неудобно, просто пришли оригинал (ссылкой на Drive или положи в «Загрузки»), сожму сама.

## Как подключить

Запись в `models/manifest.json`:

```json
"characters": {
  "naruto": {"file": "characters/naruto.glb", "height": 1.68, "faceMaterial": "Face",
             "faces": {"smile": "faces/naruto_smile.webp", "sad": "faces/naruto_sad.webp"}}
},
"locations": {
  "loc_funeral": {"file": "locations/friedhof_celle.glb", "offset": [-12.7, 40.55, 0], "rotY": 0}
}
```

- `height`: рост в метрах, модель масштабируется под него и ставится ногами на землю.
- `offset`, `rotY`, `scale` у локации: куда сдвинуть модель, чтобы персонажи стояли в нужном месте.
- `keepPlaceholder`: сколько первых кусков заглушки оставить (например ровную землю).
- `bones`, `axes`: если кости названы не как в Mixamo или позы гнут их не в ту сторону.

Пока у персонажа или локации нет файла, в игре стоит заглушка из кода, ничего не ломается.
