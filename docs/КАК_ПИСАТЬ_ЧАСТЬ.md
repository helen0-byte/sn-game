# Как устроена часть

Каждая часть лежит в своём файле `js/parts/pN_имя.js` и записана в `js/parts/index.js` (там же её замок).
Пример с пустыми местами под текст: `js/parts/p0_pohorony.js`. Пример всех эффектов: `js/parts/demo.js`.

```js
SN.stage.defineShot("p0_grave", {           // мизансцена: кто где стоит и откуда камера
  env: "funeral",                           // локация (заглушка или модель из manifest)
  cast: { naruto: [x, z, поворот, "поза"], sai: [...] },
  cam: [x, y, z], look: [x, y, z], face: "sad", shiver: 1 });

SN.part({
  id: "p0", n: 0, title: "Похороны", start: "a1",
  nodes: {
    a1: { shot: "p0_grave", place: "подпись в углу", mood: "heroin",   // mood держится, пока стоит на экранах
          text: S => ["абзац", S.f.fire ? "строка, если был пожар" : null],
          ch: [ /* выборы */ ] }
  },
  endings: {
    canon: { title: "…", canon: true, text: [...] },
    dead:  { title: "…", death: true, fallback: "canon", text: [...] }
  }
});
```

## Выбор

| поле | что делает |
|---|---|
| `t` | текст строки |
| `to` | куда дальше: id экрана или `"E:концовка"` |
| `fx` | счётчики: `{warm:1, death:1, "t:sai":1}` (`t:` это нить по человеку) |
| `set` | флаги: `{wantsLive:true, saidAloud:true}` |
| `pre` | строка курсивом в начале следующего экрана |
| `when` | `S => …` строку видно только при условии |
| `lock` | `S => …` строку видно, но она закрыта прошлым выбором |
| `struck: true` | зачёркнутая: жать можно сколько угодно, Наруто не двигается; `flinch: "toes"` или `"shoulder"` |
| `body: {ghost, body}` | «тело делает своё»: контур делает позу `ghost`, тело делает позу `body` |
| `effect` | `"blackout"`, `"leave"`, `"harm"` (`effectOpt:{remembers:false}` даёт белый), `"choke"` (`effectOpt:{focus:"crack"}`) |
| `confess: true` | только с ним работает `fx:{lie:-1}` («Я соврал») |

## Правила, которые движок проверяет сам

- В каждом экране должна быть хотя бы одна незачёркнутая строка.
- Кнопок «умереть», «вылечиться», «перестать нуждаться» быть не может (ошибка в консоли).
- Смертельная концовка (`death:true`) открывается только если не пришла ни одна нить. Иначе игра уводит в `fallback`.
- Ложь Саске уменьшается только признанием.

## Счётчики и флаги

Счётчики: `warm` тепло, `truth` правда, `own` своё, `death` тяга к смерти, `lie` ложь Саске, `kurama` интерес Курамы, `blame` чья вина.
Нити: `S.t.sai`, `S.t.sasuke`… заводятся сами при первом `fx`.
Флаги: `wantsLive` хочет жить, `saidAloud` сказал вслух, `hidan` работал на Хидана, `taught` научил, `gaaraFree` Гаара отпущен, `catechismNo` катехизис отвергнут, `fire` пожар.
Всё это переходит в следующую часть и попадает в код `SN-…`.

## Позы

`stand, walk, sit, table, eyes, upside, lean, ground, rock, reach_up, look_up, look_down, kneel, wall, hold_hand, glow, hugged, slump`
и позы Курамы `k_…`, мужика `m_…` (список в `js/core/stage.js`, объект `P`).

## Текст

Второе лицо, настоящее время. Канонные реплики дословно из фика. Альтернативы помечаются концовкой с `canon:false` («этого в фике не было»).


## Музыка

У экрана может быть поле `music`: `music:"ero"` плавно (2,5 с) переключает на трек, `music:null` уводит в тишину. Если поля нет, играет то, что играло. Список треков и настроений лежит в `audio/music/music.json`, лицензии в `docs/МУЗЫКА.md`. Музыка идёт через тот же фильтр, что и `muffle`, поэтому героин и самоповреждение глушат её сами. В меню играет заглавная тема (`theme` в music.json). Из кода: `SN.audio.music(id, {fade, vol, loop, then})`.
